# Wheelchair Basketball
This player lineup calculator supports NWBA adult Divisions I, II, and III; NWBA Intercollegiate and Women's Divisions; and IWBF official competitions.

You can select 5 players, each assigned a point value reflecting their functional ability. The NWBA classifies players from 1.0 to 4.5 points, with lower numbers indicating greater impairment and higher numbers indicating less. The calculator shows the base classification total against the selected rules' standard limit: 15.0 for NWBA adult Divisions I–III and Women's Division, and 14.0 for NWBA Intercollegiate and IWBF. Intercollegiate lineups with four or fewer players have an 11.0-point limit. Division III also limits lineups to two players classified 3.5 or higher. NWBA policy includes a one-point classification reduction for women playing on men's teams and a 16-point allowance for adult lineups with a woman on court. The calculator does not apply either adjustment; consult the current event rules before relying on the result for eligibility.

Rule sources: [NWBA classification](https://www.nwba.org/classification), [NWBA 2024–25 rule book](https://cdn1.sportngin.com/attachments/document/60aa-3225486/2024-2025_NWBA_Rule_Book.pdf), [NWBA Women's Division regulations](https://cdn1.sportngin.com/attachments/document/3578-3114054/WD_guidelines_2023_updates.pdf), [NWBA intercollegiate guidelines](https://cdn1.sportngin.com/attachments/document/4378-3553227/Intercollegiate_Division_Guidelines_-_2025-2026_-_Not_Formatted.pdf), [NWBA policies and procedures](https://cdn1.sportngin.com/attachments/document/9ab1-3089082/NWBA_Policies_and_Procedures_-_Revised_Oct_23__2023.pdf), and [IWBF classification](https://www.iwbf.org/our-sport/classification).

Visitors can add, edit, and remove player names, jersey numbers, and classifications in the browser. Jersey numbers are shown for reference; only classifications count toward the total. Changes are saved in that browser. The **Remove all players** and **Restore starter list** actions use an on-page confirmation. The site does not have a shared roster or server-side storage.

Classification is selected from the eight IWBF/NWBA classes: 1.0, 1.5, 2.0, 2.5, 3.0, 3.5, 4.0, and 4.5.
