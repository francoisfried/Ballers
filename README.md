# Wheelchair Basketball
This player lineup calculator supports NWBA adult Divisions I, II, and III; NWBA Intercollegiate and Women's Divisions; and IWBF official competitions.

You can select 5 players, each assigned a point value reflecting their functional ability. The NWBA classifies players from 1.0 to 4.5 points, with lower numbers indicating greater impairment and higher numbers indicating less. The calculator shows the classification total against the selected competition's standard limit: 15.0 for NWBA adult Divisions I–III and Women's Division, and 14.0 for NWBA Intercollegiate and IWBF. Division III also limits lineups to two players classified 3.5 or higher. Other adjustments, such as those for a woman playing on a men's team, are not modeled; consult the current event rules before relying on the result for eligibility.

Rule sources: [NWBA classification](https://www.nwba.org/classification), [NWBA rule book](https://cdn1.sportngin.com/attachments/document/a6a3-2994457/2023-24_NWBA_Rule_Book.pdf), [NWBA policies and procedures](https://cdn1.sportngin.com/attachments/document/9ab1-3089082/NWBA_Policies_and_Procedures_-_Revised_Oct_23__2023.pdf), and [IWBF classification](https://www.iwbf.org/our-sport/classification).

Visitors can add, edit, and remove player names, player numbers, and classifications in the browser. Player numbers are shown for reference; only classifications count toward the total. Changes are saved locally on that device; the original roster can be restored with the button below the player list. The site does not have a shared roster or server-side storage.

Classification is selected from the eight IWBF/NWBA classes: 1.0, 1.5, 2.0, 2.5, 3.0, 3.5, 4.0, and 4.5.
